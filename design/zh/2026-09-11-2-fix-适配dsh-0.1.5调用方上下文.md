# 2026-09-11-2-fix-适配dsh-0.1.5调用方上下文

## 直接原因

dsh 升到 `0.1.5-rc.2` 后，输入行插槽的两个条目崩溃：

```
Uncaught Error: cannot get property "remote.session" without inject
  at Proxy.directoryFor (service.ts:78)
  at inject (model-picker/index.ts:23)
slot entry crashed in 'conversation.input.right'
```

0.1.5 起，服务方法在**调用方的 Context** 下运行（cordis `getTraceable` 把 traceable 代理的 `this.ctx` 绑到调用方 fiber）。官方 `ui-model-selection` 的 `ModelDirectoryResolver` 自身声明了 `static inject = ['sessions', 'remote', 'remote.session']`，并且 `directoryFor()` 内部读 `this.ctx.sessions` / `this.ctx.remote.session`。本插件调用 `ctx.modelDirectories.directoryFor(sessionId)` 时，`this.ctx` 即本插件的 client fiber，而它当时只声明了 `['slots','locale','settingsScope','modelDirectories','connection']`，缺这三个服务，于是解析即抛错。

## 解决方案

`src/client/index.ts` 的 client 插件 `inject` 补齐为：

```
'slots', 'locale', 'settingsScope', 'modelDirectories', 'connection',
'sessions', 'remote', 'remote.session',
```

并补上对应的 Context merge 类型导入（`@deepseek-ai/dsh-api-session-controller/client` 提供 `ctx.sessions`，`@deepseek-ai/dsh-api-remotes/client` 提供 `ctx.remote` / `ctx.remote.session`），`@deepseek-ai/dsh-api-remotes` 作为浏览器/类型关系加入 devDependencies 与 `dsh.client.inject` 清单。

## 思路

- 与官方 `ui-model-selection` 的写法对齐：官方 client 的 `inject` 正是 `['commandUi','locale','sessions','slots','remote','remote.session']`——它声明这三个服务的唯一原因就是 `directoryFor()` 要在调用方 ctx 下读它们。
- 受影响的是注册进 `conversation.input.right` 的两个条目（`provider-label`、`model-picker`），二者共用 client 插件 ctx，故在插件级 `inject` 补一处即可覆盖。
- 已核查其余被调服务无同类隐患：`ui-settings` 的 `SettingsScopeBinder.bind()` 用 `this.owner`（ui-settings 自身 ctx）构造 controller、`describe()` 返回其自建 mirror，因此设置页不需要 `remote.settings`；`ui-slots` 与 `connection` 内部不读嵌套服务（`grep this.ctx.<服务>` 无命中）。
- `connection.rpc.handle` 的 0.1.5 缺陷不适用：本插件只用 `connection.rpc.call('/api', ...)` 调官方 Gateway（`open-dsh-folder`），未自建物理路由。

## 涉及文件

- [src/client/index.ts](../../src/client/index.ts)：client 插件 `inject` 增加 `sessions` / `remote` / `remote.session`，并补类型 merge 导入。
- [package.json](../../package.json)：devDependencies 增加 `@deepseek-ai/dsh-api-remotes`；`dsh.client.inject` 增加该行。
