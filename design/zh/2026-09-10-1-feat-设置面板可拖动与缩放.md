# 2026-09-10-1-feat-设置面板可拖动与缩放

## 直接原因

用户希望在设置页中直接调整设置面板的位置与大小，方便对比内容或配合多显示器使用。

## 解决方案

设置面板是 `ui-settings-general` 的 `SettingsRoot` 渲染的 `.panel`：位于 flex 居中容器内、宽 800、高 `min(800px, 100vh-48px)`，无定位与缩放能力。本插件沿用 `settings.action` list 槽注册增强组件，不改 dsh 本体：

- 组件挂载时用 `closest('[role="dialog"]')` 找到面板 DOM，把内联样式改为 `position: fixed` 并保持当前 `left/top/width/height`，视觉无跳动；卸载时清空内联样式，回到 CSS 默认的居中 800 宽。
- 拖动位置：actions 区渲染一个抓取手柄（pointer capture + rAF 节流，参照 `ui-layout` AppFrame 的列宽手柄模式）。拖动以起点相对于面板左上角的偏移计算，抬手后把面板钳制在视口内（左上角不小于 0，右下角不越出视口）。
- 拖动大小：经 `createPortal` 在面板右下角挂一个缩放柄，以左上角为锚向右下扩展；最小 480x320，最大受视口限制，缩放后同样约束可见范围。
- 视野约束：面板几何持久化到 localStorage；每次打开先应用持久化几何，再钳制到当前视口。浏览器窗口尺寸变化时监听 `resize`（rAF 合帧），先收窄超出视口的宽高，再钳位位置，设置框始终留在视野内；窗口 resize 与挂载时都把当前视觉几何写回持久化，保证下次打开所见即上次关闭状态。
- 最小尺寸：窗口允许时面板宽高不低于 480x320（窗口被压到比最小尺寸还小时仍随窗口收缩适配视口，此时不写持久化，避免把临时压扁的几何存下来；窗口拉回后尺寸恢复至少 480x320，不会塌成一条线）。

两个手柄均为按钮，带 aria-label 无障碍名。配置开关 `settings-frame` 默认开启，可经设置页关闭。

设置页列表本身做了两处排版约束：内容最大宽 520px（面板被拖宽后开关不会与文字拉开过远），相邻选项之间用 0.5px 分隔线隔开便于观看。

## 思路

- 位置：复用 `settings.action` list 槽，插件自注册增强条目，不动 `ui-settings-general` 声明，符合 dsh.md 协作规则。
- 交互：纯指针事件 + 内联样式，无需 Host 侧改动、无新 Remote；几何经 localStorage 持久化（参照 `dsh.conversation.contentWidth` 的既有做法）；手势基线与 dsh 现有拖动组件一致。
- 恢复：卸载即还原 CSS 负责的默认样式，无残留状态；最小 480x320 + 视口钳制防止面板被移出视口后无法操作。
